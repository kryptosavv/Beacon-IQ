# 🗼 Beacon IQ

Beacon IQ is a momentum and swing-trading research system combining a **TradingView indicator for chart-level analysis** with a **universe-level screener for discovering setups and breakout events**.

## 📡 Beacon IQ Screener

The screener scans the stock universe and identifies candidates across three stages:

**DRY-UP → SETUP**  
**NEAR 52W HIGH → WATCH**  
**BREAKOUTS → TRIGGER**

### Dry-Up
Identifies stocks showing:

- Stage 2 trend
- Controlled base
- Position near 52-week highs
- Volume contraction
- Strong relative strength

**Question:** What is setting up?

### Near 52W High
Identifies stocks trading close to their 52-week high.

**Question:** What should be watched?

### Breakouts
Identifies confirmed price triggers with:

- RS Score ≥ 60
- Vol Ratio ≥ 1.3×

Breakout types include:

- Stage 2 Breakout
- 52W High Breakout
- Base Breakout
- 50D Breakout
- 20D Breakout

**Question:** What has triggered?

## 📊 Beacon IQ Indicator

The TradingView indicator provides chart-level context for individual stocks.

It helps visualize and interpret:

- Trend structure
- Relative strength
- Volume behaviour
- Volume dry-up
- Position relative to 52-week highs
- Stage 2 conditions
- Price breakouts

**Question:** What does this stock look like right now?

## 🧠 Core Framework

**PRICE STRUCTURE + RELATIVE STRENGTH + VOLUME**

- **Price Structure** identifies the setup or trigger.
- **Relative Strength** measures leadership relative to the market.
- **Volume** measures contraction and participation.

The screener finds the candidates.  
The indicator provides the chart-level context.

## 🔄 Workflow

**NSE UNIVERSE → BEACON IQ SCREENER → SETUP / WATCH / TRIGGER → TRADINGVIEW → BEACON IQ INDICATOR → CHART REVIEW → TRADE DECISION**

> **Beacon IQ Screener tells you where to look. Beacon IQ Indicator helps you understand what you’re seeing.**

Beacon IQ is a research and discovery system, not an automated buy/sell system. Final decisions should still consider market context, entry quality, risk, stop-loss placement, and position sizing.
